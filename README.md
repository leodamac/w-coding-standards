Descripción
El programa permite:
Crear estudiantes con un ID y nombre únicos.
Agregar notas numéricas en el rango 0–100.
Calcular el promedio de las notas.
Determinar la carta de calificación (A, B, C, D, F).
Determinar si el estudiante aprobó o reprobó.
Detectar si el estudiante pertenece al cuadro de honor.
Eliminar notas por índice.
Generar un reporte formateado por estudiante.

Todo esto con manejo explícito de errores para que entradas inválidas no hagan colapsar el programa.

Requisitos
Python (se usó 3.11 en el CI)
Pylint (para análisis estático)
pylint-json2html (para generar reportes HTML)
Visual Studio Code con la extensión oficial de Python (recomendado)
